# DoublyLinkedList Data Structure

## Overview

This project implements a **Doubly Linked List** (DLL) data structure in C++, which allows bidirectional traversal of the list. Each node in a doubly linked list contains a data field and two pointers: one pointing to the next node and one pointing to the previous node. This structure provides greater flexibility than a singly linked list because elements can be traversed in both directions.

### Features:
- **Bidirectional Traversal**: The list can be traversed from the head to the tail (forward traversal) and from the tail to the head (backward traversal).
- **Dynamic Size**: The list can grow and shrink dynamically as elements are added or removed.
- **Efficient Operations**: The doubly linked list supports efficient insertions and deletions from both ends of the list.

## Problem Statement

A **Doubly Linked List** is a linear data structure where each node points to both its previous and next node. The primary goal of this project is to implement a doubly linked list that supports standard operations like insertion, deletion, searching, and traversal.

### Key Operations to Implement:
1. **Insert at the Head**: Insert a new node at the beginning of the list.
2. **Insert at the Tail**: Insert a new node at the end of the list.
3. **Delete a Node**: Delete a node with a specific value or at a given position.
4. **Search**: Search for a node with a specific value.
5. **Traverse Forward**: Traverse the list from head to tail.
6. **Traverse Backward**: Traverse the list from tail to head.
7. **Get Size**: Return the number of elements in the list.
